# Documentación del proyecto

Esta documentación describe la implementación actual del sitio de AN Asociados.

## Guías

- [Arquitectura y generación](arquitectura.md): estructura de fuentes, rutas, layouts y recursos.
- [Contenido y mantenimiento](contenido.md): dónde editar páginas, datos e imágenes.
- [Desarrollo y publicación](desarrollo-publicacion.md): requisitos, comandos y salida generada.

## Alcance actual

El proyecto genera un sitio estático. No incluye servidor de aplicación ni una configuración de despliegue automatizado dentro del repositorio. Los servicios de terceros que aparecen en las plantillas (analítica, tipografías y bibliotecas CDN) se cargan desde el navegador.
